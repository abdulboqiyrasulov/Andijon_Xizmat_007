# Sartaroshxona — onlayn yozilish sayti

Mijoz xizmat va vaqt tanlab yoziladi; sartarosh (admin) xizmatlarni boshqaradi va yozilishlarni ko'radi.

- Mijoz sahifasi: `index.html`
- Admin kirish: `admin.html` (boshlang'ich login: `admin`, parol: `admin123`)
- Admin paneli: `panel.html`

Sayt oddiy HTML/CSS/JS, serversiz ishlaydi. Ma'lumotlar foydalanuvchi brauzerida (localStorage) saqlanadi.

## GitHub Pages orqali joylashtirish

Repozitoriy: **Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.**
